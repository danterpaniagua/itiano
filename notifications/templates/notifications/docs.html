Notifications

In-app notifications for events other users or teams should know about — e.g. a credential shared with your team, or a Jira reconciliation run completing.

Where they show up
  • The bell icon in the top navbar shows an unread count and the most recent notifications.
  • The full notifications page lists everything, newest first.
Current triggers
  • Vault: sharing a credential with a team, or granting a container to a team, notifies every current member of that team.
  • Jira reconcile: when jira_reconcile finishes, it notifies whichever users are configured in Settings → Jira (staff only).
Read state

Each notification is per-recipient — marking one read (or "mark all read") only affects your own view; it never affects other recipients of a team-wide notification.
