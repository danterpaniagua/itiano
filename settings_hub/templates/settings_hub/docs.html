Settings Hub

Staff-only section to manage cross-app configuration from the frontend without needing Django admin.

Tags

Tags can be applied to tickets manually or automatically via the Automations engine.

  • Each tag has a name and an optional color.
  • Tags in use (assigned to one or more tickets) cannot be deleted.
  • Rename or recolor a tag at any time — changes apply immediately to all tickets.
Categories

Categories classify tickets by service area or topic.

  • Deleting a category does not affect tickets — their category field is set to None.
  • Categories can be assigned when creating or editing a ticket.
