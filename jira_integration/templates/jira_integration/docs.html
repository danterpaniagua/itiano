Jira Integration

Itiano listens for Jira webhook events and creates tickets automatically via the Automations engine.

Webhook Setup
  1. In Jira, go to Settings → System → Webhooks.
  2. Create a new webhook pointing to: /jira/webhook/
  3. Select the events: Issue created, Issue updated.
  4. Save. Jira will POST a payload to Itiano on each matching event.
