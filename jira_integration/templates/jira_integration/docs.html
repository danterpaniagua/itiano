Jira Integration

Itiano listens for Jira webhook events and creates tickets automatically via the Automations engine.

Webhook Setup
  1. In Jira, go to Settings → System → Webhooks.
  2. Create a new webhook pointing to: /jira/webhook/
  3. Select the events: Issue created, Issue updated.
  4. Save. Jira will POST a payload to Itiano on each matching event.

Jira Tab on ITSM Tickets

When a Jira automation creates an ITSM ticket, it sets the ticket's External ID to the Jira issue key. Itiano uses this link to show a Jira tab on the ticket detail page with the issue's current status, labels, and attached files.

Attachment metadata (filename, author, date, download URL) is read from the most recent webhook payload — no additional Jira API calls are made. The tab is hidden if no matching Jira ticket is found.
