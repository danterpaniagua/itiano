Clipboard

A personal markdown scratchpad. Content is private to each user and encrypted at rest.

Usage
  • Write markdown in Edit mode.
  • Switch to Preview to render it.
  • Press Save — your content persists across sessions.
Markdown support

Standard markdown syntax is supported: headings, bold, italic, lists, code blocks, links, and tables.

Security

Content is stored encrypted in the database using AES-128 symmetric encryption (Fernet). The encryption key is derived from the application's SECRET_KEY.

Important: If the application's SECRET_KEY is rotated, existing clipboard content will become unreadable. Do not store content you cannot afford to lose.
