JSON Sandbox

The Sandbox is a staff tool for testing JSONPath expressions and automation filter conditions against a raw JSON payload before creating triggers.

Modes
  • JSONPath — Evaluate a JSONPath expression against a payload and see the matched values.
  • Filter — Evaluate a full automation filter condition tree and see whether it matches.
JSONPath Tips
  • $.field — top-level field
  • $.issue.fields.status.name — nested field
  • $.issue.fields.labels[0] — first element of an array
  • $.issue.fields.labels[*] — all elements of an array
  • Missing paths return no results — the filter evaluates to false.
