# v5.8.18 — Credential Vault: Search, Sort & Tags Filter

## Goal

Improve discoverability in the credential list with text search, sort options, and a multiselect Tags dropdown matching the pattern established in v5.8.11 and v5.8.14.

## Current State

- `/vault/` has a single-tag filter (`GET.get('tag')`) — single-value, inline UI.
- No text search.
- No sort options — credentials appear in default DB order.

## In Scope

- **Text search**: filter credentials by `name`, `username`, or `url` (case-insensitive contains). Search input preserved alongside tag filter.
- **Sort toggle**: Name A–Z, Date added (newest first), Expiry date (soonest first). Default: Name A–Z. Sort state preserved across filter changes.
- **Tags multiselect dropdown**: replace the single-tag select with the Bootstrap dropdown + checkbox pattern from v5.8.11. Per-chip deselect. Clear button. Filter applies to both owned and team-visible credentials.
- All three filters (search + tags + sort) work together and preserve state across each other.
- Mobile-friendly: dropdowns stack full-width.

## Out of Scope

- Folder/group filtering (v5.8.19).
- Assignee or type filtering.
- Saved filter presets.

## Technical Changes

- `vault/views.py` — `credential_list`:
  - `q = GET.get('q', '')` for text search.
  - `selected_tags = GET.getlist('tags')` (upgrade from single `tag`).
  - `sort = GET.get('sort', 'name')` with valid choices `('name', 'created', 'expiry')`.
  - Apply filters and order to queryset.
  - Collect `all_tags` from visible credentials.
  - Pass `q`, `selected_tags`, `all_tags`, `sort` to template.
- `vault/templates/vault/credential_list.html`:
  - Search input.
  - Tags dropdown (v5.8.11 pattern).
  - Sort buttons or select.
  - Active chips with per-chip deselect.
  - All filter state carried across form submissions.

## Acceptance Criteria

- Searching "github" returns only credentials where name/username/url contains "github".
- Selecting multiple tags filters to credentials with ALL selected tags.
- Sort by Name, Date, Expiry each produce correct ordering.
- All three filters combine (AND logic).
- Switching sort preserves active tags and search.
- Mobile: full-width dropdowns, no horizontal scroll.

## Dependencies

- v5.8.17 (security fixes) ✅ Delivered.
- v5.8.14 (filter pattern) ✅ Delivered — reuse same dropdown/chip HTML.
