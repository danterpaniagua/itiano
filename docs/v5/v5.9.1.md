# Goal

Remove the "Time by Tag" card from the top row of the daily time report and widen the remaining two cards (In Progress+Done, Time by Status) to fill the freed space.

# In Scope

- Remove the "Time by Tag" card and its top-row column entirely.
- Widen In Progress+Done and Time by Status columns from `col-12 col-md-4` (3-column layout) to `col-12 col-md-6` (2-column layout).
- Remove the now-dead `pct`/`color` computation on `tag_totals` that only fed the removed card's bar rendering (the underlying `tag_totals` query itself was kept — it still feeds the separate Time by Project/Time by Environment pill section further down the page).

# Out of Scope

- The Time by Project / Time by Environment section (pill UI, hierarchy mode) — untouched, still consumes `tag_totals`.
- Any change to Time by Status, In Progress, or Done panel content/logic.
- Gantt, Status History pivot, or any other section below the top row.

# Technical Changes

### `timetracking/templates/timetracking/report.html`
- Top-row comment: `{# ── Top row: In Progress + Time by Status + Time by Tag ── #}` → `{# ── Top row: In Progress + Time by Status ── #}`.
- Left column (`In Progress` + `Done`): `col-12 col-md-4` → `col-12 col-md-6`.
- `Time by Status` column: `col-12 col-md-4` → `col-12 col-md-6`.
- `Time by Tag` card block (card-header + bar rows + empty state) deleted entirely from the top row.

### `timetracking/views.py`
- Removed the `if tag_totals: _max_tag_secs = ...` block (~`DailyReportView`, near the `status_totals` pct/color computation) that computed `pct`/`color` per tag — dead code once the card consuming it was removed.
