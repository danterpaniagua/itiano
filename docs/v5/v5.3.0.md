# v5.3.0 — Jira Activity Log on Ticket Detail

## Goal

Show all Jira webhook events received for a linked ticket in the Jira tab of the ticket detail page. Currently only attachments are surfaced; changelog entries, status changes, and comments recorded by the webhook are invisible.

## In Scope

- Two sub-tabs inside the Jira tab: **Attachments** and **Activity**.
- Activity lists all `JiraEvent` records for the linked `JiraTicket`, ordered newest first.
- Each activity entry shows: received date, event type (human-readable), and summary.
- Mobile-friendly: single-column list for activity, existing responsive table/card for attachments.
- **Tab state persistence**: active tab (main and Jira sub-tabs) saved to URL hash via `history.replaceState`; restored on page load/refresh.

## Out of Scope

- Fetching live activity from the Jira API
- Filtering or paginating events
- Any other tab or template

## Technical Changes

- `itsm/views.py` — pass `jira_events` queryset to context in `TicketDetailView`
- `itsm/templates/itsm/ticket_detail.html` — Activity section inside `#panel-jira`

## Acceptance Criteria

- Ticket with linked Jira issue (e.g. #31 / GITIN-1352): Jira tab shows all received events in the Activity section, newest first.
- Each entry displays date, formatted event type, and summary.
- Ticket without Jira link: no change.
- No layout regression on mobile.
