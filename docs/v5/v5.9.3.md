# Goal

Replace the id-only label in the Timeline (Gantt) card on the time-tracking report with a two-line label — ticket title as primary text, `issue_key` as small/muted secondary text — matching the existing Status History pivot card pattern on the same page.

# In Scope

- `timetracking/templates/timetracking/report.html`, Gantt Timeline section (~lines 421-531): standalone rows, parent rows, and child rows.
- Widen the label column (~110px→170px for standalone/parent rows, ~90px→140px for child rows), left-align instead of right-align.
- Two-line label: title (`truncatechars`, `fw-semibold small`) on top, `issue_key` (`small text-muted`) below — same visual weighting as the Status History card (report.html:553-555).
- Increase row height to fit two lines (~28px→36px standalone/parent, ~26px→34px child) so label rows stay vertically aligned with their bar rows.
- Wrap the whole label block (title + id) in the existing link to `timetracking-ticket-timeline`, preserving all current query-string params (`back_range`, `back_tags`, `back_statuses`).

# Out of Scope

- Any change to bar computation, `gantt_ticks`, `gantt_legend`, or `views.py` — this is a pure template/markup change.
- Any change to the Status History pivot card itself — it's the reference pattern, left untouched.
- Any change to `ticket_timeline.html`'s all-time Status History section.
- Introducing a mobile card layout for the Gantt Timeline — it is already desktop-only (`overflow-x:auto`, no `d-md-none` variant) and stays that way; not requested here.

# Delivery Note (amended — actual shipped implementation diverged from plan)

Committed as `e96f4a0`. Iterated twice on user feedback after the initial version landed:

- **Id text size**: shrunk further than planned, to `0.68rem` (standalone/parent) / `0.66rem` (child) via inline `style`, instead of relying on Bootstrap's `.small` class alone (user feedback: "Smaller ID. Too big").
- **Title truncation**: single-line `truncatechars` + CSS ellipsis was replaced with a 2-line clamp (`-webkit-line-clamp:2`) so more title text is visible per row (user feedback: "need to see more title chars"). `truncatechars` limits were raised to 100/90 (standalone/parent, child) purely as a safety net — the CSS clamp does the real visual truncation now, not the character count.
- **Row heights**: ended up taller than originally scoped to fit the 2-line title: 48px (standalone/parent) and 44px (child), not 36px/34px.
- Column widths (170px/140px) and the axis/grid-line offset recalculation matched the original plan.

Verified via isolated Django template rendering with real GITIN ticket data (not just a static mockup) before and after each iteration — see conversation history for the rendered artifacts. `docker compose exec app python manage.py test timetracking` was not run (no automated test suite covers this template); live verification via `agent_test` in-browser was also not completed (their account had no active Gantt data at the time) — noted as pending in the original delivery, still pending as of this archival.
