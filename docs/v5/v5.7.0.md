# v5.7.0 — Time Report Dashboard

## Goal

Replace the current flat "all entries grouped by date" report with a structured dashboard
that shows totals, today's work, and a per-ticket status history pivot.

## In Scope

### Top — Totals (C)

- Summary chips showing total hours logged across all time, grouped by the ticket's current Jira status
  - e.g. In Progress: 12h | Done: 4h | Backlog: 1h
- Highlighted callout: hours logged today against In Progress tickets specifically
  - e.g. "In Progress today: 2h 30m"

### Middle — Today (A)

- Table of all In Progress tickets assigned to the user (from `jira_username` setting)
- Each row shows: Ticket | Title | Time logged today (0 / blank if none yet) | Log time button
- Uses the same active ticket filter as v5.6.0 (`status__iexact=In Progress`, `assignee__iexact=jira_username`)
- If `jira_username` not configured: prompt to set it in Settings
- If no active tickets: quiet empty state

### Bottom — Status history pivot (B)

- Rows = all tickets the user has ever logged time against
- Columns = all distinct Jira statuses those tickets have passed through (derived from JiraEvent changelog items, same source as v5.5.2)
- Cells = time spent in that status (Jira's clock, not logged time)
- Ongoing status marked visually (e.g. badge or indicator)
- Final column: user's total logged time for that ticket (sum of TimeEntry.minutes)

## Out of Scope

- Date range filter on totals or pivot (future)
- Filtering pivot to only today's tickets
- Manager visibility of other users' reports
- Exporting the report

## Technical Changes

- `timetracking/views.py` — rewrite `DailyReportView` with three context sections:
  1. `status_totals`: total hours per current ticket status across all entries
  2. `today_rows`: active In Progress tickets assigned to the user + hours logged today per ticket
  3. `pivot_rows`: per-ticket status history (from JiraEvent changelog) + total logged time
- `timetracking/templates/timetracking/report.html` — full redesign with three sections

## Acceptance Criteria

- Totals chips show correct cumulative hours per current ticket status.
- "In Progress today" callout shows only today's hours on In Progress tickets (0 if none).
- Today's table shows all In Progress tickets assigned to the user, with time logged today per ticket.
- Today's table is useful before any time is logged (shows 0 / blank for unlogged tickets).
- "Log time" button per row pre-fills the ticket in the create form.
- Pivot shows all tickets the user has logged time against, with one column per status seen.
- Pivot cells show duration in Jira's status (from changelog events), not logged time.
- Ongoing status is visually marked.
- Last pivot column shows the user's total logged time per ticket.
- Page loads without error when the user has no time entries at all.

## Validation Plan

- Log time against two tickets with different statuses → verify totals chips update.
- Log time today against an In Progress ticket → verify callout shows correct hours.
- Verify today's table shows only today's entries.
- Open pivot → verify columns match the distinct statuses seen across tickets.
- Verify ongoing status cell is marked.
- Access as user with zero entries → verify page loads cleanly.
