# Goal

Rename the current time report page from `/time/report/` to **`/time/current/`** so `/time/report/` is free
for the new tag time report (v5.21.0).

# Background

- `DailyReportView` lives at `/time/report/` (name `timetracking-report`); its per-ticket timeline at
  `/time/report/ticket/<key>/` (name `timetracking-ticket-timeline`).
- The URL name is used in 7 files (dashboard, entry list, map, ticket timeline, in-app docs, tests, urls).
- `notifications.rules.ticket_url` builds `/time/report/ticket/<KEY>/timeline/`, a path that never matched
  the route (it 404s today).

# Premise (rules)

1. `/time/report/` -> `/time/current/`, name `timetracking-report` -> `timetracking-current`.
2. The timeline moves to `/time/current/ticket/<key>/`; its URL name stays `timetracking-ticket-timeline`.
3. Until v5.21.0, `/time/report/` and `/time/report/ticket/<key>/` redirect (302, query string kept) to
   the new paths so bookmarks and existing notifications keep working. v5.21.0 removes them.
4. Page titles and button labels keep their text ("Time Report"); naming the two pages is decided in
   v5.21.0 when the new report exists. Behaviour of the page does not change.
5. The notification link is built with `reverse()`, which also fixes its 404 (same line, needed anyway).

# In Scope

- `timetracking/urls.py`, the five templates and `timetracking/tests.py` that use the old name,
  `notifications/rules.py` + its test, `.claude/feature_timetracking_report.md`, new route tests.

# Out of Scope

- The tag time report and its prompt (v5.21.0), renaming labels, editing historical docs (`docs/v5/`,
  `docs/mockup/`).

# Technical Changes

- Routes and names only; no model, migration or template logic change.

# Acceptance Criteria

- `/time/current/` and `/time/current/ticket/<key>/` work; the old paths redirect with the query string.
- No template links to `/time/report/`; the notification link opens the timeline.

# Validation Plan

- `docker build -t itiano-app:v5.20.0 .` then
  `docker run --rm --network itiano_default --env-file .env -e DB_HOST=db --entrypoint python itiano-app:v5.20.0 manage.py test timetracking notifications core --noinput`

# Related Scope Dependencies

- Required by v5.21.0. Remove the temporary redirects there.
