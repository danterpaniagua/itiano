# Goal

Show Paused in the Time Report as a grouped column with **Blocked**, **Overlapped** and **Total** sub-columns, and give
every tag section and the grand total real total rows under the same columns.

# Background

- v5.21.0 shipped Blocked and Paused as two columns and the totals as a text line, so Overlapped never showed in the
  table and the totals did not line up with the columns.
- Summed Blocked and Paused totals add parallel waits (tickets are blocked at the same time), so they can exceed the
  elapsed working time; this was reported after generating October's report.

# Premise (rules)

1. Header: `Paused` spans three sub-columns, `Blocked | Overlapped | Total` (Total = Blocked + Overlapped).
2. Each tag section ends with a subtotal row; a grand total row (each ticket once) follows, all under the same
   columns (shared `<colgroup>` widths).
3. The Blocked and Paused totals get a hover hint: sum of each ticket's wait, tickets are blocked in parallel.
4. Mobile: cards and totals read `IP · Paused (Blocked + Overlapped)`. The prompt does not change.

# In Scope

- `tag_report.html`, `_tag_report_cols.html`, `tag_report._totals` / `decorate` (Overlapped total and label),
  tests, docs (`feature_timetracking_tag_report.md`, in-app docs).

# Out of Scope

- The stored `prompt_time_report` note (still without the transition-map legend), a Restore default action, v5.22.0.

# Acceptance Criteria

- Paused shows Blocked, Overlapped and Total per ticket, per section and in the grand total; Total = Blocked +
  Overlapped; works at mobile width without horizontal scroll (table inside `table-responsive`, cards on mobile).
