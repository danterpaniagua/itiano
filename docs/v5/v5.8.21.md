# v5.8.21 — User Avatar & Profile Picture

## Goal

Add avatar support to User Personal Info: custom upload with Gravatar fallback, displayed in the settings page, navbar, and Django admin. Also show last login in admin user list.

## In Scope

- `UserProfile` model (OneToOne → `User`) with `avatar` ImageField in `settings_hub`
- Gravatar fallback using MD5 of user email when no custom avatar is set
- Avatar upload and remove on `/settings/user/` Personal Info section
- Avatar displayed in navbar (small circle next to username)
- Django admin: avatar thumbnail + last login column on `UserAdmin`
- Add `Pillow` to `requirements.txt`

## Out of Scope

- Avatar display in ticket views, reports, or other pages
- Admin management of other users' avatars

## Technical Changes

- New model `UserProfile` in `settings_hub/models.py` (OneToOne → User, avatar ImageField nullable)
- Migration `settings_hub/migrations/0003_userprofile.py`
- `Pillow` added to `requirements.txt`
- Template tag or view helper `avatar_url(user)` — returns custom avatar URL or Gravatar URL
- `UserSettingsView` handles `avatar` file upload and delete action
- `UserAdmin` extended in `settings_hub/admin.py` or `core` with `avatar_thumbnail` and `last_login` readonly fields
- Navbar template updated to show avatar circle
- `MEDIA_ROOT`/`MEDIA_URL` already configured — no settings change needed

## Acceptance Criteria

- [ ] User can upload a profile picture on `/settings/user/`
- [ ] User can remove a custom avatar (reverts to Gravatar)
- [ ] Gravatar shown when no custom avatar is set, using user's email
- [ ] Avatar shown in navbar as a small circle
- [ ] Django admin user list shows avatar thumbnail and last login column
- [ ] Mobile-first: avatar upload section works on small screens
- [ ] `Pillow` listed in `requirements.txt`

## Validation Plan

- Upload an avatar → confirm it appears in settings and navbar
- Remove avatar → confirm Gravatar appears
- User with no email → Gravatar fallback renders without error
- Admin user list → avatar thumbnail and last login visible

## Related Scope Dependencies

- Depends on: `feature_settings_hub.md` (UserSettingsView, `/settings/user/`)
- Unblocks: avatar display in future ticket/report views
