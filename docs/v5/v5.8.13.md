# v5.8.13 — Time Report: Custom Date Range Picker

## Goal

Allow users to select an arbitrary date range in `/time/report/` instead of being limited to the three fixed presets (Today / Week / Month).

## Current State

- `DailyReportView` accepts `?range=today|week|month`. Any other value falls back to `today`.
- All panels (Time by Status, Time by Tag, In Progress, Gantt, Status History) compute their data relative to these fixed boundaries.
- No way to view, e.g., "last 2 days" or "a specific Monday to Friday."

## In Scope

- Add two `<input type="date">` fields (`date_from`, `date_to`) to the range bar in `report.html`.
- When submitted, `range_param` becomes `'custom'` and `DailyReportView` computes `start_dt` from `date_from` (midnight in user's timezone) and end boundary from `date_to` (end of day in user's timezone).
- Clamp: if `date_to < date_from`, set `date_to = date_from`.
- Today / Week / Month buttons remain. When a custom range is active, none of them appear highlighted (`outline-secondary` for all three).
- Custom `date_from` / `date_to` values preserved across filter changes: all tag/status filter forms and range toggle carry them as hidden inputs when `range_param == 'custom'`.
- Active chips row shows the custom range as a readable label (e.g., "12/06 – 18/06") when custom is active.
- Falls back to `today` if `date_from` is missing or invalid.
- Gantt X axis ticks adapt: custom ranges use daily ticks (like `week`) or hourly (if single day).

## Out of Scope

- Hour/minute granularity on the custom range.
- Saving or naming date range presets.
- Changing the Gantt tick strategy beyond the single-day → hourly rule.

## Technical Changes

- `timetracking/views.py` — `DailyReportView.get`:
  - Accept `range_param = 'custom'`.
  - Read `date_from` / `date_to` from GET when `range_param == 'custom'`.
  - Compute `start_dt` and `end_dt` from the custom dates.
  - Pass `date_from`, `date_to`, `range_param` to template.
  - Gantt tick strategy: single day → hourly; multi-day → daily.
- `timetracking/templates/timetracking/report.html`:
  - Add from/to date inputs in the range bar.
  - Submit with a hidden `range=custom` input.
  - All filter forms carry `date_from` / `date_to` / `range=custom` when active.
  - Active chips row: show custom range label.
  - Range buttons: none highlighted when `range_param == 'custom'`.

## Acceptance Criteria

- User selects a custom date range and all panels reflect that range.
- Today / Week / Month buttons still work and clear the custom range.
- Custom range preserved when changing tag or status filters.
- Single-day custom range uses hourly Gantt ticks; multi-day uses daily.
- Invalid or missing `date_from` falls back to today.
