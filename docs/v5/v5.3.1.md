# v5.3.1 — Clipboard as Private System Note

## Goal

Convert the Clipboard storage into a special Note in the Notes app. The note is private (not shareable) and cannot be deleted. Existing clipboard content is migrated automatically on first access.

## In Scope

- `Note` gets an `is_system` flag. System notes are auto-created per user, cannot be deleted, and cannot be shared.
- The Clipboard full-page view (`/clipboard/`) redirects to the system note's edit page.
- The offcanvas clipboard (nav) continues to work via `clipboard-content` and `clipboard-save`, now backed by the system Note body instead of `ClipboardEntry`.
- Existing encrypted clipboard content is decrypted and migrated to the system note on first access.
- Notes list marks system notes with a lock icon and hides Delete / Share buttons for them.
- Note edit page hides the Share button and notebook selector for system notes.

## Out of Scope

- Removing the `ClipboardEntry` model or its migration (left in place to avoid data loss)
- Encrypting Note body content
- Any other system note type beyond "Clipboard"

## Technical Changes

- `notes/models.py` — add `is_system = BooleanField(default=False)`
- `notes/migrations/0002_note_is_system.py` — migration
- `notes/views.py` — block delete and share for system notes
- `notes/templates/notes/note_list.html` — lock icon, hide delete/share for system notes
- `notes/templates/notes/note_edit.html` — hide share button and notebook selector for system notes
- `clipboard/views.py` — `clipboard` redirects to system note; `clipboard_content` / `clipboard_save` use Note body; migrate on first access
- `clipboard/utils.py` — `get_or_create_clipboard_note(user)` helper
- `core/templates/core/dashboard.html` — update Clipboard card description to "Personal private note"

## Acceptance Criteria

- Clicking Clipboard in nav opens offcanvas; content loads from the system Note.
- Saving from offcanvas updates the system Note body.
- `/clipboard/` redirects to the system note edit page.
- Delete button absent (or blocked) on the system note.
- Share button absent on the system note.
- System note appears in Notes list with a lock icon.
- Existing clipboard content migrated to the system note on first access.
