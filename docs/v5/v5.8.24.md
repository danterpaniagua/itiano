# v5.8.24 — In Progress bar on report

## Goal

Add an "In Progress" timeline bar above the Gantt on `/time/report/` showing the union of all In Progress periods across the user's tickets for the selected range. Off-hours areas are visually shaded darker. Hovering a bar segment shows contributing ticket keys and titles.

## In Scope

- New card between top cards row and the Timeline/Gantt section
- Single horizontal bar: union of all In Progress segments in the selected range
- Off-hours shading: areas outside `WorkSchedule.start_time`–`end_time` (and non-working days) are darkened
- Bars split at work-hour boundaries: a segment crossing 08:00 renders as one continuous bar over both shaded and unshaded areas
- Hover tooltip: ticket `issue_key: title` for each ticket contributing to that segment
- Time axis ticks: hour-level for today, day-level for week/month
- Card hidden when no In Progress activity in the selected range

## Out of Scope

- Color differentiation between work and off-hours bars (shading conveys it)
- Per-ticket rows inside the bar
- Summary stats (work hours / off hours totals)

## Technical Changes

- `timetracking/views.py` — compute `daily_ip_bars` with per-segment ticket list; compute `daily_off_shades` from WorkSchedule per day in range
- `timetracking/templates/timetracking/report.html` — new card with CSS bar, off-shade overlays, Bootstrap tooltips

## Acceptance Criteria

- [ ] Bar appears above Timeline when user has In Progress activity in range
- [ ] Off-hours areas are visually darker
- [ ] Bar spanning work-hour boundary renders correctly (one bar, two backgrounds)
- [ ] Hover shows ticket key + title for that segment
- [ ] Hidden when no IP activity in range
- [ ] Works for today, week, month and custom range

## Validation Plan

- Week: confirm day ticks and per-day shading
- No activity: card hidden
