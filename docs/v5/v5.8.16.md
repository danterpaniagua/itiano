# v5.8.16 — Ticket Timeline: Jira Comments

## Goal

Show Jira comment events in the per-ticket activity timeline (`/time/report/ticket/<key>/`). Comments are now delivered via the Jira webhook (configured June 2026) and stored as `JiraEvent` records with `payload.comment`.

## Current State

- `TicketTimelineView` processes `JiraEvent.payload.changelog.items` only — status transitions and field changes.
- Comment events (`issue_event_type_name: issue_comment_created` / `issue_comment_edited`) arrive with `payload.comment.body`, `payload.comment.author.displayName`, `payload.comment.created` but are not displayed.
- Timeline order is newest-to-oldest (currently oldest-to-newest — fix here too per user request).

## In Scope

- `timetracking/views.py` — `TicketTimelineView.get`:
  - For each `JiraEvent` in the date range, check `payload.get('comment', {})`.
  - If present and non-empty, add a `type: 'comment'` entry to the timeline with `author`, `body`, `at` (from `payload.comment.created` ISO string, or `event.received_at` as fallback).
  - **Reverse timeline order**: sort descending (`sort_key` reversed) so newest activity appears first.
- `timetracking/templates/timetracking/ticket_timeline.html`:
  - Add comment row style: author name + comment body (full text, no truncation for body in detail view).
  - Desktop table: new row type with distinct background (e.g., `table-info`), speech-bubble icon (`bi-chat-left-text`).
  - Mobile cards: distinct background, author + body.
  - Update empty state text if needed.

## Out of Scope

- Editing or deleting comments from the timeline.
- Comment threading or replies.
- Comment events in the Gantt chart.
- Backfilling comments for events received before Jira webhook was configured.

## Technical Changes

- `timetracking/views.py` — `TicketTimelineView.get`: comment extraction + sort reversal.
- `timetracking/templates/timetracking/ticket_timeline.html`: comment row rendering in both desktop and mobile layouts.

## Acceptance Criteria

- Comment events received after Jira webhook reconfiguration appear in the timeline.
- Comments show author display name and full body text.
- Timeline is ordered newest first.
- Tickets with no comments: no change to existing behavior.
- Tickets with only comments (no changelog): comments appear, no crash.

## Dependencies

- v5.8.12 (ticket timeline view) ✅ Delivered.
- Jira webhook configured to send comment events ✅ Done (June 2026).
