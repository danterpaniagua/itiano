# v5.7.2 — Fix Disabled Save/Apply Buttons on Trigger & Action Edit

## Goal

Save and Apply buttons are always disabled when editing a Trigger or Action because
`buttons_enabled` is missing from the render context on edit views.

## In Scope

- Pass `buttons_enabled: True` in `action_edit` render context
- Pass `buttons_enabled: True` in `trigger_edit` render context

## Out of Scope

- Changes to the JS enable logic
- Changes to create views (already correct)

## Technical Changes

- `automations/views.py` — add `'buttons_enabled': True` to both edit view render calls

## Acceptance Criteria

- Editing an existing Action: Save and Apply buttons are enabled on page load
- Editing an existing Trigger: Save and Apply buttons are enabled on page load
- Create views unaffected

## Validation Plan

- Navigate to an existing Action edit page — buttons must be enabled
- Navigate to an existing Trigger edit page — buttons must be enabled
