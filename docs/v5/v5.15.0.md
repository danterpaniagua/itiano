# Goal

Give the "Time by Environment" card on `/time/report/` an All/Labor toggle plus a per-tag donut
chart, so a user can switch between raw In-Progress time and time scoped to their configured
`WorkSchedule`. The "Time by Project" card is unaffected — it keeps its current single-bar look.

# In Scope

- `timetracking/views.py` (`DailyReportView.get`): extend the `tag_totals` computation (lines
  ~660-693) to also aggregate per-tag **labor seconds**, using the existing
  `working_seconds_bounds(seg_start, seg_end)` helper (lines 303-322) against each contributing
  ticket's In-Progress segments — the same primitive already used for the Blocked/Testing/Backlog
  rows of Time by Status and for stuck-ticket detection.
- Each entry in `tag_totals` (and its JSON-serialized form, `tag_totals_json`) gains `labor_secs`
  and a formatted `labor_display`, alongside the existing `secs`/`display`. Additive fields —
  `Time by Project`'s renderer ignores them, so its output is unchanged.
- `timetracking/templates/timetracking/report.html`: **Environment card only**
  - `[All | Labor]` toggle in the card header (`btn-group btn-group-sm`, same pattern as the
    existing auto-update/zoom toggles). Switches which value (`secs` vs `labor_secs`) drives the
    donut, legend, and bar list. Preference persisted in `localStorage` (`itiano_tbe_mode`).
  - A small donut chart (per-tag categorical colors, center label = total for the active mode) +
    legend (swatch, tag, %, value) above the existing bar list.
  - The bar list keeps its current layout but switches from a single fixed green fill to
    per-tag categorical colors matching the donut/legend, and its values follow the active mode.
  - Colors assigned by each tag's alphabetical position in a fixed 8-hue categorical palette
    (validated with the `dataviz` skill's palette validator — all-pairs CVD/contrast pass for the
    first 3 slots), never by sorted rank, so a tag's color never changes when the list re-sorts by
    value or the user changes selection.
  - The **Project** card (`key === 'project'`) is untouched: same single-color bar, same data
    shape (new fields simply unused).
- Mobile-first: toggle wraps under the card title (`d-flex flex-wrap`), donut shrinks, legend and
  bar list remain single-column with no horizontal scroll.

# Out of Scope

- Any change to the Time by Project card's rendering or data usage.
- Any other report panel (Time by Status, Gantt, Status History pivot, In Progress Today column).
- A general Working Hours / All toggle across the whole report page — that remains the broader,
  deferred idea tracked in `deferred_working_hours_mode.md`; this scope is a narrower, concrete
  instance limited to the Environment card.
- New WorkSchedule configuration UI (existing `/settings` schedule editor is reused as-is).
- Caching or backfilling historical labor totals — computed live per request, same as today's
  `tag_totals`.
- Per-slice hover tooltips beyond the native `title` attribute (full tooltip UI, if wanted, is a
  follow-up).

# Technical Changes

- `timetracking/views.py`: `tag_totals` aggregation extended to compute `labor_secs`/
  `labor_display` per tag via `working_seconds_bounds()`, mirroring the existing raw-seconds walk.
- `timetracking/templates/timetracking/report.html`:
  - Environment card markup: toggle buttons, donut container (CSS `conic-gradient`, no chart
    library), legend container.
  - CSS: `.env-mode-toggle`, `.env-donut-*`, `.env-legend-*` (styles validated against the repo's
    Mobile-First UI rules).
  - JS: `render(key)` forks — Environment gets `renderEnvDonut()` + per-tag colored bars driven by
    `envMode`; Project keeps its original single-bar path unchanged. Toggle click handler persists
    `envMode` to `localStorage` and re-renders.
- `.claude/feature_timetracking_report.md`: update the "Time by Project / Time by Environment (pill
  UI fallback)" section to document the toggle + donut, scoped to Environment only.

# Acceptance Criteria

- On `/time/report/`, Time by Environment shows a donut + legend + colored bar list; clicking
  `Labor` recomputes all three to `labor_secs`, clicking `All` reverts to `secs`, without a page
  reload.
- Donut/legend/bar colors are consistent per tag and stable across re-selection and mode switches.
- Time by Project is pixel-for-pixel unchanged: single blue bar, no toggle, no donut, no legend.
- No horizontal scroll or clipped text at mobile widths (checked at a narrow viewport).
- A user with no `WorkSchedule` configured sees 0 for every tag in Labor mode (empty donut/bars),
  without errors.
