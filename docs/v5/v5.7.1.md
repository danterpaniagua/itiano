# v5.7.1 — Jira Deleted Ticket Flag

## Goal

Allow staff to mark Jira tickets as deleted so they are excluded from the time report,
active ticket panel, and status pivot, while remaining visible in the ticket list for management.

## In Scope

- Add `is_deleted` boolean field (default False) to `JiraTicket`
- Migration
- Checkbox on the Jira ticket detail page (staff only) to toggle `is_deleted`
- Deleted tickets excluded from:
  - Time report active panel (A — In Progress now)
  - Time report status pivot (B)
  - Time report totals (C)
  - Active ticket panel on `/time/` (entry list)
- Deleted tickets remain visible in `/jira/` ticket list with a "Deleted" badge
- Known deleted tickets: GITIN-1341, GITIN-1343

## Out of Scope

- Automatic detection of deleted tickets via Jira API
- Webhook-based deletion sync
- Per-user hiding of tickets

## Technical Changes

- `jira_integration/models.py` — add `is_deleted` to `JiraTicket`
- `jira_integration/migrations/` — new migration
- `jira_integration/views.py` — toggle view (staff only POST), badge in ticket list
- `jira_integration/templates/jira_integration/ticket_detail.html` — staff checkbox
- `jira_integration/templates/jira_integration/ticket_list.html` — deleted badge
- `timetracking/views.py` — filter `is_deleted=False` in `DailyReportView` and `TimeEntryListView`

## Acceptance Criteria

- Staff can check/uncheck "Mark as deleted" on a Jira ticket detail page.
- GITIN-1341 and GITIN-1343 marked as deleted → disappear from report and active panel.
- Deleted tickets show a "Deleted" badge in the ticket list.
- Non-staff users do not see the checkbox.
- Time report and active panel only show non-deleted tickets.
