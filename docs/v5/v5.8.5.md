# v5.8.5 — Status History: Full Title Visibility

## Goal

Make the ticket title readable in the Status History pivot without requiring horizontal scrolling or a separate detail page visit.

## Current State

The Ticket column in the pivot shows the issue key and title truncated at 30 characters with no way to see the rest. Users sometimes need to read the full title to identify the ticket.

## In Scope

- Expand title truncation from 30 to 60 characters in the Status History pivot
- Add a `title` attribute (tooltip) to the title element so hovering reveals the full title on desktop
- No column resize controls

## Out of Scope

- Resizable table columns
- Inline title expand/collapse toggle
- Changes to any other panel or template

## Technical Changes

- `timetracking/templates/timetracking/report.html`:
  - Change `truncatechars:30` to `truncatechars:60` on the pivot title element
  - Add `title="{{ row.ticket.title }}"` to the title `<div>`

## Acceptance Criteria

- Status History pivot shows up to 60 characters of the title
- Hovering over the truncated title on desktop shows the full title via tooltip
- No layout breakage on mobile

## Validation Plan

- Open report with a ticket whose title exceeds 30 chars — more text now visible
- Hover over title — full title appears in tooltip
- View on mobile — no horizontal overflow introduced
