# v5.8.8 — Navbar User Dropdown (Profile + Settings)

## Goal

Replace the plain username text in the navbar with a Bootstrap dropdown showing the user's name, with links to Profile and Settings (and Logout). "Settings" links to the existing `/time/schedule/` page where jira username, working hours, and (after v5.8.7) timezone are configured.

## Current State

The navbar right-side shows `{{ user.username }}` as a static `<span>` with a role badge, plus a separate Logout button. There is no user-facing profile page and no easy path from the navbar to personal settings.

## In Scope

- Replace the username `<span>` and Logout button in `base.html` with a single Bootstrap dropdown:
  - Header: `{{ user.username }}` + role badge (non-clickable)
  - Divider
  - **Profile** — links to a new `/profile/` page
  - **Settings** — links to `/time/schedule/`
  - Divider
  - **Logout** — POST form inside the dropdown (same as current)
- New `/profile/` page (`core` app): shows username, role, full name (from linked Contact if present), email (from User), member since date
- URL: `path('profile/', views.profile, name='profile')` in `core/urls.py`
- View + template in `core`

## Out of Scope

- Editing profile fields (read-only in this scope)
- Avatar / photo upload
- Password change
- Any changes to the Settings page itself (that is v5.8.7)
- Notification preferences or any other settings

## Technical Changes

- `core/templates/base.html`: replace username `<span>` + logout button with Bootstrap dropdown
- `core/views.py`: add `profile` view
- `core/urls.py`: add `path('profile/', ...)` 
- `core/templates/core/profile.html`: new template (extends base.html)

## Acceptance Criteria

- Navbar shows username as a dropdown toggle
- Dropdown contains: username + role badge (header), Profile link, Settings link, Logout
- Clicking Profile renders `/profile/` showing username, role, full name (or "—"), member since
- Clicking Settings navigates to `/time/schedule/`
- Logout still works via POST

## Validation Plan

- Open any page — navbar right shows username as clickable dropdown
- Open dropdown — see Profile, Settings, Logout items
- Click Profile → `/profile/` loads with user info
- Click Settings → `/time/schedule/` loads
- Click Logout → logs out

## Dependencies

- No hard blocker. Recommended to deliver after v5.8.7 so the Settings page linked from the dropdown already includes the timezone field, but not required.
