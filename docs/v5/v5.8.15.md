# v5.8.15 — Dashboard: Jira In Progress Time

## Goal

Replace the manual `TimeEntry` hours shown in the dashboard Time Tracking card with Jira In Progress time derived from status transition events. Gives users an accurate view of how long they've been actively working today and this week based on Jira ticket history.

## Current State

- `core/views.py` `dashboard()` computes `today_hours` and `weekly_hours` from `TimeEntry.objects.filter(user=request.user)` — manual log entries only.
- Users who track time via Jira status changes (In Progress transitions) see `0.0h` if they haven't created manual entries.

## In Scope

- `core/views.py` — `dashboard()`:
  - Read `WorkSchedule.jira_username` for the current user.
  - If set, fetch all `JiraTicket` assigned to that username.
  - For each ticket, extract status segments from `JiraEvent` changelog (same logic as `DailyReportView`).
  - Compute `today_ip_minutes`: seconds in `In Progress` segments that overlap today (midnight local to now) using the user's `WorkSchedule.timezone`.
  - Compute `weekly_ip_minutes`: seconds in `In Progress` segments that overlap the current week (Monday midnight to now).
  - Pass `today_ip_hours` and `weekly_ip_hours` to the dashboard template.
- `core/templates/core/dashboard.html` — Time Tracking card:
  - Replace manual entry hours with Jira In Progress hours.
  - Update labels to reflect the source (e.g., "In Progress today").

## Out of Scope

- Manual `TimeEntry` totals (still accessible via `/time/`).
- Working hours filtering (only calendar time, not schedule-constrained).
- Per-ticket breakdown on the dashboard.

## Technical Changes

- `core/views.py` — extend `dashboard()` with Jira segment computation.
- `core/templates/core/dashboard.html` — update Time Tracking card labels and values.

## Acceptance Criteria

- User with `jira_username` set sees In Progress time for today and this week on the dashboard card.
- User with no `WorkSchedule` or no `jira_username` sees `0.0h` (no error).
- "View report →" link continues to point to `/time/report/`.

## Dependencies

- v5.8.12 (Gantt/timeline, segment logic pattern) ✅ Delivered.
