# v5.2.1 — Apply Button on Actions and Triggers

## Goal

Add an Apply button to the Action and Trigger edit forms that saves the form and stays on the current edit page, allowing staff to iterate quickly without losing their place.

## In Scope

- **Apply button** on action and trigger edit forms: saves form changes and redirects back to the same edit page (instead of returning to the list).
- **Save button** retains existing behavior: saves and returns to the list.
- **Buttons disabled until form changes**: both Save and Apply are disabled on page load; enabled on first input/change event.
- No-op handling: if Apply is clicked with no changes, shows an info message and stays on the edit page.

## Out of Scope

- Re-dispatching automation payloads from the edit form
- Apply on create forms (buttons always enabled for new records)
- Bulk apply across multiple actions or triggers

## Technical Changes

- `automations/views.py` — `action_edit` and `trigger_edit` detect `'_apply' in request.POST`; redirect to edit page if true, list if false
- `automations/views.py` — `action_create` and `trigger_create` pass `buttons_enabled: True`
- `automations/templates/automations/action_form.html` — Apply button (`name="_apply" value="1"`); buttons disabled unless `buttons_enabled` or change detected
- `automations/templates/automations/trigger_form.html` — same button pattern + enable-on-change JS
- `automations/urls.py` — no new routes needed (removed `action_apply`/`trigger_apply` URL patterns)

## Acceptance Criteria

- Staff clicks Apply on an action edit → form saved → redirected back to same edit page → success message shown.
- Staff clicks Apply on a trigger edit → same behavior.
- Staff clicks Save → form saved → redirected to list.
- Buttons are disabled on page load (edit forms); enabled after any field change.
- No changes + Apply → info message, stay on edit page.
- Non-staff → 403.

## Validation Plan

- Edit action → change name → click Apply → verify redirect back to edit page with success message.
- Edit trigger → change name → click Apply → verify same.
- Open edit form without changing anything → verify Save and Apply are disabled.
- Change a field → verify buttons become enabled.
- Click Save → verify redirect to list.
