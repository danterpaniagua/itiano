# v5.0.0 — Notes App

## Goal

A Joplin-style per-user note-taking app with notebooks, markdown editor, and note sharing. Accessible as a full-page app from a dedicated navbar button. The existing clipboard offcanvas is unchanged.

## In Scope

### Models

- `Notebook` — name, owner (FK User), created_at
- `Note` — title, body (TextField, markdown), notebook (FK Notebook, nullable), owner (FK User), created_at, updated_at
- `NoteShare` — note (FK Note), shared_with (FK User), permission (`read` / `write`)

### Views and URLs (`/notes/`)

- `NoteListView` — main page: notebook sidebar + note list, filtered by notebook
- `NoteDetailView` — read-only view for shared notes with read permission
- `NoteEditView` — create/edit note with Write/Preview tabs; accessible to owner or shared write users
- `NoteDeleteView` — owner only
- `NotebookCreateView` — create a notebook
- `NotebookDeleteView` — owner only, must be empty
- `NoteShareView` — manage shares: add/remove users, set read/write permission

### UI

- Desktop: two-column layout — notebook + note list on the left, editor/viewer on the right
- Mobile: single column, navigate between list and editor
- Editor: Write tab (textarea) + Preview tab (rendered markdown)
- Navbar button: `📓 Notes` linking to `/notes/`
- Shared notes: visible in a "Shared with me" section in the sidebar

### Dashboard card

- Add Notes card to `core/templates/core/dashboard.html` showing note count

### Docs section

- `notes/templates/notes/docs.html` fragment
- Tab added to `core/templates/core/docs.html`

### Permissions

- Owner: full control (read, edit, delete, share)
- Shared write: can edit body and title, cannot delete or share
- Shared read: read-only view
- Users not in either group: 404

## Out of Scope

- Rich text / WYSIWYG editor
- File attachments on notes
- Public/link sharing (URL-based access without login)
- Note history / versioning
- Real-time collaborative editing
- Encryption at rest
- Search (deferred to v5.1.0)
- Mobile app

## Acceptance Criteria

- User can create notebooks and notes
- Markdown body renders correctly in Preview tab
- Owner can share a note with read or write permission
- Shared-write user can edit; shared-read user cannot
- Non-shared user gets 404
- Shared notes appear in "Shared with me" sidebar section
- Notebook delete is blocked if it contains notes
- Dashboard card shows correct note count
- Mobile layout is usable without horizontal scroll

## Validation Plan

- Create a notebook and two notes → verify list and editor
- Preview tab renders markdown headings, bold, code blocks
- Share a note as read → log in as other user → verify read-only
- Share a note as write → log in as other user → verify editable
- Access a note as unshared user → verify 404
- Delete a non-empty notebook → verify blocked
- Mobile: sidebar collapses, editor is full-width
