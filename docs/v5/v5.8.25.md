# v5.8.25 — User Avatar & Profile Picture

**Status: Delivered.**

## Goal

Add avatar support to User Personal Info: upload a custom image or fall back to Gravatar. Show in settings, navbar, and Django admin.

## In Scope

- `avatar` ImageField + `avatar_url()` Gravatar fallback on `UserProfile`
- Migration `0003_userprofile_avatar` (depends on `0002_userprofile_jira_account_id`)
- `Pillow` added to `requirements.txt`
- Avatar upload/remove on `/settings/user/` Personal Info section
- Avatar circle (32px) in navbar
- Django admin: avatar thumbnail + `last_login` column on `UserAdmin`

## Out of Scope

- Avatar in ticket views, reports, or other pages
- Admin management of other users' avatars

## Technical Changes

- `core/models.py` — add `avatar` + `avatar_url()` to `UserProfile`
- `core/migrations/0003_userprofile_avatar.py`
- `requirements.txt` — add Pillow
- `core/admin.py` — `avatar_thumb` display + `last_login` on `CustomUserAdmin`
- `core/templates/base.html` — avatar `<img>` in navbar dropdown toggle
- `settings_hub/views.py` — avatar upload/remove actions extending existing `_get_profile()` and `jira_account_id` save (must not overwrite)
- `settings_hub/templates/settings_hub/user_settings.html` — avatar section in Personal Info

## Constraints

- `settings_hub/views.py` already has `_get_profile()` and saves `jira_account_id` — avatar upload must be added as separate POST actions, not replace existing save logic
- `base.html` already uses `user.userprofile.role` — avatar_url() must never raise

## Acceptance Criteria

- [ ] User can upload a profile picture on `/settings/user/`
- [ ] User can remove avatar (reverts to Gravatar)
- [ ] Avatar shown in navbar (32px circle)
- [ ] Admin user list shows avatar thumbnail and last login
- [ ] No regression on `jira_account_id` save in settings
- [ ] Mobile-first: upload section works on small screens

## Validation Plan

- Upload avatar → appears in navbar and settings
- Remove avatar → Gravatar shown
- Save schedule settings → `jira_account_id` still saves correctly
- Admin user list → thumbnail and last login visible
