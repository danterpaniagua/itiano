# v5.8.32 — Time by Project & Time by Environment Cards

## Goal

Add two new aggregation cards to `/time/report/` that let the user group IP time by a user-selected subset of tags. One card for project tags, one for environment tags. Selections persist in `localStorage`.

## In Scope

- New row (`col-12 col-md-6` each) below the existing top row and above the IP bar
- **Time by Project** card: inline tag pills + `+ add` dropdown + bar chart (blue)
- **Time by Environment** card: same, independent selection (green)
- Tag pills: show selected tags with × to remove
- `+ add` dropdown: lists unselected tags available in `tag_totals`
- Bar chart: relative bars, shows `display` time per tag, sorted by seconds descending
- Empty state when no tags selected
- Selections saved to `localStorage` keys `itiano_tbp_tags` and `itiano_tbe_tags`
- Restored on page load; falls back to empty if no stored value
- Small view change: embed `tag_totals` as `<script type="application/json" id="tag-totals-data">`
- Mobile-first: cards stack on mobile

## Out of Scope

- Tag model changes (no `group` or `category` field)
- New backend endpoints
- Affecting existing "Time by Tag" card
- Server-side persistence of selections

## Technical Changes

### `timetracking/views.py`
- Add `tag_totals_json` to render context: HTML-safe JSON of `tag_totals` list (`[{tag, secs, display}]`)

### `timetracking/templates/timetracking/report.html`
- Embed `<script type="application/json" id="tag-totals-data">{{ tag_totals_json|safe }}</script>`
- New row div after the existing top row, before the IP bar section
- Two cards with pill rows and bar containers
- JS block: `renderGroup(key)`, `addTag(key, name)`, `removeTag(key, name)`, `toggleDropdown(key)`, init from localStorage

## Acceptance Criteria

- [ ] Two cards appear in a new row below Time by Status / Time by Tag
- [ ] Each card independently tracks its own tag selection
- [ ] `+ add` dropdown shows only tags present in `tag_totals` (tags with IP time in range)
- [ ] Removing all tags shows empty state
- [ ] Adding a tag updates bar chart immediately
- [ ] Selections survive page reload via `localStorage`
- [ ] Cards stack on mobile (no horizontal scroll)
- [ ] Cards hidden entirely when `tag_totals` is empty (no IP tag data in range)
