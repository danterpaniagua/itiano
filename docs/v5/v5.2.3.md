# v5.2.3 — Fix +Tag Button on Ticket Detail

## Goal

The +Tag button on the ticket detail page does not reveal the tag form when clicked. The click handler removes `d-none` from the wrong element (the outer wrapper instead of `#tag-add-form` itself), so the form stays hidden and the button disappears with no visible result.

## In Scope

- Fix the `btn-add-tag` click handler to toggle `d-none` on `#tag-add-form` directly.
- Fix the cancel handler (`btn-cancel-tag`) to restore `#tag-add-form` to `d-none` instead of the parent wrapper.

## Out of Scope

- Any other tag behavior
- Mobile-specific workarounds

## Technical Changes

- `itsm/templates/itsm/ticket_detail.html` — two JS lines in the tag IIFE

## Acceptance Criteria

- Clicking +Tag reveals the tag form.
- Clicking Cancel hides the tag form and restores the +Tag button.
- No regression on existing tag display or submission.
