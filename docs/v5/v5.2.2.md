# v5.2.2 — Jira Description Table Formatting Toggle

## Goal

Ticket descriptions sourced from Jira often contain raw HTML tables with no visible borders. Add a per-ticket toggle that applies Bootstrap-compatible CSS to those tables (and other Jira HTML elements) without changing the stored content.

## In Scope

- Toggle button beside the "Description" heading on `ticket_detail.html`.
- When ON: scoped CSS applied to the description div — table borders, thead background, td padding, horizontal scroll for wide tables, code/pre styling, blockquote styling.
- When OFF: raw rendering (current behavior).
- Toggle state persisted in `localStorage` (key: `itiano_desc_enhance`).
- Button uses Bootstrap Icons; active state visually distinct.

## Out of Scope

- Applying formatting to the ticket edit form
- Persisting preference server-side
- Any other template

## Technical Changes

- `itsm/templates/itsm/ticket_detail.html` — toggle button, `<style>` block, JS in `extra_js`

## Acceptance Criteria

- Ticket with Jira HTML tables: toggle ON shows visible table borders and styled headers; toggle OFF shows raw output.
- Toggle state survives page reload.
- No layout regressions on tickets without tables.
