# v5.8.3 — Jira Ticket List: Label Filter

## Goal

Add multi-label filtering to the Jira ticket list. Labels are already stored as a JSONField array on `JiraTicket` and displayed in the list. This scope adds a filter bar that lets users narrow tickets by one or more labels.

## Current State

`/jira/` lists all tickets with labels shown as badges in the desktop table and mobile cards. There is no filter bar — `ticket_list` does no filtering.

## In Scope

- Filter bar above the ticket list with a multi-value label selector
- Filter via GET param `?labels=LABEL1&labels=LABEL2` (repeatable param, AND logic — ticket must have all selected labels)
- Label dropdown/selector populated from all distinct labels currently in the database
- Active filter chips displayed with individual remove links
- Ticket count reflects the filtered result
- Mobile card list and desktop table both respect the filter
- Preserve existing active filters when adding or removing individual labels

## Out of Scope

- OR logic (any label match) — AND is the useful default for this dataset
- Saving filters per user
- Free-text label search
- Status, assignee, or project filters (separate future scope if needed)

## Technical Changes

- `jira_integration/views.py` — `ticket_list`:
  - Read `?labels` GET params (multi-value)
  - Filter queryset: `tickets = tickets.filter(labels__contains=[label])` chained for each label
  - Collect all distinct labels for the dropdown (from all tickets before filtering)
  - Pass `selected_labels`, `all_labels`, `tickets` to template
- `jira_integration/templates/jira_integration/ticket_list.html`:
  - Filter bar: label checkboxes, submit on change via JS
  - Active label chips row with `×` remove links
  - Responsive: filter bar stacks on mobile

## Acceptance Criteria

- Filter bar appears above the ticket list with a label selector
- Selecting one label narrows the list to tickets that carry that label
- Selecting two labels shows only tickets that have BOTH labels
- Active labels shown as removable chips; clicking `×` removes that label from the filter
- Ticket count reflects the filtered result
- No labels selected = all tickets shown (current behavior)
- Mobile card list respects the same filter

## Validation Plan

- Load `/jira/` — all tickets listed, no filter active
- Select label "INFRADEVOPS" — list narrows to tickets with that label
- Select a second label — list narrows further (AND)
- Click `×` on one chip — that label removed, other remains active
- Clear all — all tickets shown again
