# v5.2.4 — Ticket Title Filter + Jira Attachment Sort

## Goal

Two small UX improvements on the ticket detail and list pages:
1. Fast filter by title on the ticket list so users can quickly locate a ticket without paging.
2. Jira attachments sorted newest-first on the ticket detail Jira tab.

## In Scope

- **Ticket list title filter**: a text input that filters the list by title using `?q=` (GET param, `title__icontains`). Input is part of the existing filter row; no new page or view needed.
- **Jira attachment sort**: sort the `jira_attachments` list by the `created` field descending before passing it to the template.

## Out of Scope

- Full-text search across description or comments
- Server-side pagination of filtered results
- Filtering by any field other than title

## Technical Changes

- `itsm/views.py` — `TicketListView`: add `q` GET param filter; sort `jira_attachments` by `created` descending in `TicketDetailView`
- `itsm/templates/itsm/ticket_list.html` — add title search input to filter row, preserve `q` on submit

## Acceptance Criteria

- Typing a term in the title filter and submitting shows only tickets whose title contains that term (case-insensitive).
- Clearing the filter restores the full list.
- `?tag=` and `?q=` filters combine correctly.
- Jira attachments on ticket detail are listed newest first.
- No layout regression on mobile.
