# v5.5.0 — Time Tracking (core)

## Goal

Allow users to manually log hours spent on Jira tickets, with activity descriptions, and generate a daily report. Each user sees only their own entries.

## In Scope

- New `timetracking` app
- `TimeEntry` model: user, jira_ticket, date, minutes, activity
- CRUD views: list, create, edit, delete (owner-only)
- Time entries panel on the Jira ticket detail page (current user's entries + quick-add form)
- Daily report: entries grouped by date, totals per ticket per day
- Dashboard card showing total hours logged this week
- Docs section

## Out of Scope

- Work schedule / working hours calculation (v5.5.1)
- Automatic status duration tracking (v5.5.2)
- Manager visibility of other users' entries (future)

## Technical Changes

- `core/templates/core/docs.html` — docs tab

## Acceptance Criteria

- User can log a time entry (date, minutes, activity) against any Jira ticket.
- User can edit and delete their own entries only.
- Jira ticket detail shows the current user's entries for that ticket and a quick-add form.
- Report page shows entries grouped by date with per-day totals.
- Dashboard card shows total hours logged in the current week.
- No user can see another user's entries.
