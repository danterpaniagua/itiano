# v2.1.0 – JSON Sandbox

## Goal

Standalone Django app for testing JSONPath filter expressions against JSON payloads. Staff-only access. Can be pre-loaded with a payload from any app via Django session.

## In Scope

* `json_sandbox` Django app
* Single view `/sandbox/` — JSON input, JSONPath expression input, output panel
* JSONPath evaluation using `jsonpath-ng` library
* Session-based payload pre-loading: any app sets `request.session['sandbox_payload']` and redirects to `/sandbox/`
* "Open in Sandbox" button on `jira_integration` ticket detail — sends the selected event payload to the sandbox
* Access restricted to `is_staff`; permission check in one place for future group extension
* Dashboard card for Sandbox (visible to staff only)

## Out of Scope

* Persisting sandbox sessions to the database
* Sharing sandbox results
* Filter history

## Technical Changes

* New `json_sandbox` app with view, URL, and template
* `requirements.txt` — add `jsonpath-ng`
* `config/settings.py` — register `json_sandbox` in `INSTALLED_APPS`
* `config/urls.py` — include `json_sandbox` URLs
* `jira_integration/templates/jira_integration/ticket_detail.html` — "Open in Sandbox" button per event
* `jira_integration/views.py` — POST handler to load event payload into session and redirect
* `core/views.py` — sandbox card on dashboard (staff only)
* `core/templates/core/dashboard.html` — sandbox card

## Acceptance Criteria

* `/sandbox/` is accessible only to staff users; others receive 403
* Pasting valid JSON and a JSONPath expression returns the correct filtered result
* An invalid JSONPath expression returns a clear error message
* Clicking "Open in Sandbox" on a Jira event loads that event's payload into the sandbox
* Dashboard shows the Sandbox card only to staff users

## Validation Plan

* Access `/sandbox/` as a non-staff user — verify 403
* Access `/sandbox/` as staff — verify the page loads
* Submit valid JSON with `$.issue.key` — verify correct value returned
* Submit invalid JSONPath — verify error message shown
* Click "Open in Sandbox" on a Jira event — verify payload is pre-loaded in sandbox
* Verify sandbox card is visible on dashboard for staff, hidden for non-staff
