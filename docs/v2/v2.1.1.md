# v2.1.1 – Test Coverage for Jira Integration and JSON Sandbox

## Goal

Add automated test coverage for `jira_integration` (v2.0.0) and `json_sandbox` (v2.1.0) to formally validate both scopes before documentation is updated.

## In Scope

* `jira_integration/tests.py` — new test file
  * Webhook rejects non-POST methods
  * Webhook returns 403 when signature is invalid
  * Webhook returns 200 and creates `JiraTicket` + `JiraEvent` on valid payload
  * Webhook reuses existing `JiraTicket` on second event for same issue key
  * Webhook returns 200 silently when payload has no `issue` field
  * `_build_summary` returns changelog summary when items present
  * `_build_summary` returns comment author when no changelog
  * List view requires login
  * List view returns 200 and lists tickets for authenticated user
  * Detail view returns 200 and shows events for known issue key
  * Detail view returns 404 for unknown issue key
  * `open_in_sandbox` sets session payload and redirects
  * `open_in_sandbox` returns 403 for non-staff user

* `json_sandbox/tests.py` — new test file
  * `/sandbox/` returns 403 for non-staff authenticated user
  * `/sandbox/` returns 200 for staff user (GET)
  * POST with valid JSON and valid JSONPath returns correct result
  * POST with valid JSON and invalid JSONPath returns error message
  * POST with valid JSON and expression that matches nothing returns no-match warning
  * POST with invalid JSON returns JSON error message
  * Session payload is pre-loaded into textarea on GET
  * `show_back=True` when `?back=1` is in GET params
  * `show_back=True` persists through POST via hidden field
  * `show_back=False` when accessed directly without `back` param

## Out of Scope

* Tests for `itsm` or `core` apps
* End-to-end browser tests
* Load or performance tests
* Mocking the database — tests use Django's test database

## Technical Changes

* `jira_integration/tests.py` — new file
* `json_sandbox/tests.py` — new file

## Acceptance Criteria

* All tests pass when run with `python manage.py test jira_integration json_sandbox`
* No existing tests broken

## Validation Plan

* Run `python manage.py test` and confirm no regressions
