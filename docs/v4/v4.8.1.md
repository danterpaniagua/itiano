# v4.8.1 — Jira Metadata Tab on ITSM Tickets

## Goal

Show Jira origin metadata (status, labels, attachments) on ITSM tickets that were created via Jira automation, in a dedicated tab on the ticket detail page.

## In Scope

- Jira tab on `ticket_detail.html`, visible only when `ticket.external_id` matches a `JiraTicket.issue_key`
- Tab is hidden silently if no matching `JiraTicket` exists
- Tab contents:
  - Jira key (linked to `/jira/<issue_key>/`), project, type, current status, labels
  - Attachment list: filenames extracted from `JiraEvent` changelog items where `field = Attachment`

## Out of Scope

- Downloading or storing Jira file content
- Jira API calls
- Showing full Jira event log
- Jira tab on any other page

## Technical Changes

- Updated: `itsm/views.py` — look up `JiraTicket` by `ticket.external_id` and pass to context
- Updated: `itsm/templates/itsm/ticket_detail.html` — conditional Jira tab

## Acceptance Criteria

- Ticket with matching `external_id` shows a Jira tab
- Tab shows key, project, type, status, labels, and attachment filenames
- Ticket without `external_id` or with no matching `JiraTicket` shows no tab
- Mobile layout is usable without horizontal scroll
