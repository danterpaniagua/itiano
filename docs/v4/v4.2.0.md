# v4.2.0 – Per-User Encrypted Clipboard

## Goal

A personal markdown scratchpad for every authenticated user. Content is encrypted at rest using Fernet symmetric encryption and rendered client-side with marked.js.

## In Scope

* New `clipboard` Django app
* `ClipboardEntry` model — `user` (OneToOneField), `content` (TextField, Fernet ciphertext), `updated_at`
* `clipboard/crypto.py` — Fernet helpers; key derived from `settings.SECRET_KEY` via SHA-256 → base64url
* Single view at `/clipboard/` — GET renders editor, POST saves and redirects; entry auto-created on first visit
* Edit / Preview toggle via marked.js (CDN, no backend dep)
* Nav link for all authenticated users
* Dashboard card for all authenticated users
* `clipboard/templates/clipboard/docs.html` + tab in `core/templates/core/docs.html`
* `cryptography` added to `requirements.txt`
* `clipboard` added to `INSTALLED_APPS` and `config/urls.py`

## Out of Scope

* Multiple notes per user
* Note history or versioning
* Auto-save / AJAX
* Sharing between users
* Server-side markdown rendering
* Rich text editor
* Per-user encryption keys

## Technical Changes

* `clipboard/` — new app: models, crypto, views, urls, admin, migrations, templates
* `requirements.txt` — add `cryptography`
* `config/settings.py` — INSTALLED_APPS
* `config/urls.py` — include clipboard URLs
* `core/templates/core/dashboard.html` — clipboard card
* `core/templates/base.html` — Clipboard nav link + `{% block extra_js %}` slot
* `core/templates/core/docs.html` — Clipboard tab

## Acceptance Criteria

* `/clipboard/` accessible to all authenticated users; 302 to login if unauthenticated
* Content saved, retrieved, and displayed correctly across sessions
* Database column contains ciphertext, not plaintext
* Preview tab renders markdown (bold, lists, headers, code blocks)
* Dashboard card links to `/clipboard/`
* SECRET_KEY rotation caveat documented in the docs section

## Validation Plan

* Visit `/clipboard/` as a new user — verify entry created, page loads
* Save markdown content — verify it displays correctly in Preview
* Inspect DB row directly — verify content is ciphertext
* Reload page — verify content persists
* Access as unauthenticated user — verify redirect to login
