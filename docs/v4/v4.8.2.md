# v4.8.2 — App Home Navigation

## Goal

Provide a consistent home button on every detail and form page so users can reach the app's list in one click from any depth.

## In Scope

- `itsm/ticket_edit.html` — add home button → ticket-list (Cancel already goes to ticket-detail, not list)
- `automations/action_form.html` — add home button → action-list in header (only has tabs + bottom Cancel)
- `automations/trigger_form.html` — add home button → trigger-list in header (same)

Pages already covered (no changes):

- `ticket_detail.html` — Back → ticket-list ✓

- `automations/log_detail.html` — Back → log-list ✓
- `vault/credential_form.html` — Back → vault-list ✓
- `vault/import_form.html` — Back → vault-list ✓
