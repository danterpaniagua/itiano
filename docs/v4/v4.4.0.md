# v4.4.0 – Clipboard Offcanvas

## Goal

Replace full-page clipboard navigation with a Bootstrap Offcanvas panel available on every page. Content is loaded and saved via AJAX without leaving the current page.

## In Scope

* Two new endpoints in `clipboard/`:
  * `GET /clipboard/content/` — returns `{"content": "<decrypted text>"}` as JSON
  * `POST /clipboard/save/` — accepts `{"content": "..."}`, saves, returns `{"ok": true}`
* Bootstrap Offcanvas panel in `core/templates/base.html`:
  * Triggered by a navbar button (clipboard icon)
  * Textarea for editing
  * Preview toggle rendered client-side with marked.js
  * Load content on open, save on button click
* CSRF token sent via `X-CSRFToken` header in fetch calls
* Existing `/clipboard/` page kept as fallback — no deletion
* Navbar link replaced by offcanvas trigger button

## Out of Scope

* Auto-save / debounce
* Multiple notes per user
* Removing the standalone `/clipboard/` page
* Rich text editor
* Sharing between users

## Technical Changes

* `clipboard/views.py` — add `clipboard_content` (GET) and `clipboard_save` (POST) JSON views
* `clipboard/urls.py` — add routes for the two new endpoints
* `core/templates/base.html` — add offcanvas panel markup + JS; replace nav link with trigger button
* marked.js already included via `{% block extra_js %}` on clipboard page — load it globally in `base.html` instead to avoid double-loading

## Acceptance Criteria

* Clicking the clipboard icon opens the offcanvas panel
* Panel loads the user's current content on open
* Saving from the panel persists content (verify by reopening)
* Preview tab renders markdown correctly inside the panel
* Standalone `/clipboard/` page still works
* Unauthenticated users do not see the clipboard button
* CSRF errors do not occur on save

## Validation Plan

* Open any page → click clipboard icon → verify panel opens and content loads
* Edit content → save → close → reopen → verify content persists
* Switch to preview tab → verify markdown rendering
* Navigate to `/clipboard/` directly → verify page still works
* Log out → verify clipboard button not visible

## Related Scope Dependencies

* v4.2.0 — clipboard app, crypto, model, `/clipboard/` page

## Delivered

Scope implemented as approved. No deviations.

* `clipboard/views.py` — added `clipboard_content` (GET JSON) and `clipboard_save` (POST JSON) with `@login_required`, `@require_GET`/`@require_POST`, CSRF enforced via header.
* `clipboard/urls.py` — added `/clipboard/content/` and `/clipboard/save/` routes.
* `core/templates/base.html` — offcanvas panel added for authenticated users; navbar Clipboard link replaced with offcanvas trigger button; marked.js moved here globally; fetch-based load-on-open and save with status feedback.
* `clipboard/templates/clipboard/clipboard.html` — duplicate `<script>` tag for marked.js removed (now loaded globally).
* Tests: 29 passed.
