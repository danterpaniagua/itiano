# v4.4.1 – Fix Ticket Description HTML Rendering

## Goal

Ticket descriptions sourced from Jira (HTML content) are not rendering as HTML in the ticket detail view. The `render_description` filter's HTML detection regex is too narrow and misses tags Jira commonly uses.

## In Scope

* Extend `_HTML_RE` in `itsm/templatetags/itsm_filters.py` to include missing tags: `code`, `pre`, `hr`, `figure`, `img`, `section`, `article`, `header`, `footer`, `aside`
* Alternatively, replace tag-enumeration approach with a looser heuristic: detect any `<tag` pattern (any lowercase word tag) to identify HTML content
* Verify fix against actual Jira webhook payload stored in a ticket's `description` field

## Out of Scope

* Sanitizing HTML output (XSS — already handled by trusting Jira source only)
* Markdown rendering for descriptions
* Changing how the dispatcher stores descriptions

## Technical Changes

* `itsm/templatetags/itsm_filters.py` — update `_HTML_RE` regex

## Acceptance Criteria

* Jira-sourced ticket descriptions render as HTML (bold, lists, paragraphs visible)
* Plain-text descriptions (created via web form) still render with line breaks, no raw HTML tags shown
* No raw `&lt;p&gt;` escape sequences visible in the ticket detail view

## Validation Plan

* Open a ticket created from a Jira webhook → verify description renders as formatted HTML
* Open a ticket created via the web form → verify plain text renders with line breaks

## Delivered

* `itsm/templatetags/itsm_filters.py` — replaced narrow tag-enumeration regex with `r'</?[a-z][a-z0-9]*[\s/>]'`. Detects any HTML tag regardless of name.
* `automations/models.py` — `Action.description_format` field added (choices: raw, html, markdown; default: raw).
* `automations/migrations/0004_action_description_format.py` — migration for new field.
* `automations/forms.py` — `description_format` added to `ActionForm`.
* `automations/dispatcher.py` — `_normalize_description()` converts markdown to HTML via Python `markdown` library before storing. Raw and HTML pass through unchanged.
* `requirements.txt` — added `markdown==3.7`.
* Tests: 29 passed.
