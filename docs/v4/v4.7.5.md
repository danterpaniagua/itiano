# v4.7.5 — Jira Ticket Labels Display

## Goal

Show Jira labels on the ticket list main line so operators can see issue labels at a glance without opening the detail page.

## In Scope

- Add `labels = models.JSONField(default=list, blank=True)` to `JiraTicket`
- Migration for the new field
- Webhook handler extracts `$.issue.fields.labels` and saves it on every `update_or_create`
- Ticket list desktop table: labels column with small badges
- Ticket list mobile card: labels shown below issue type line

## Out of Scope

- Filtering by label from the ticket list
- Labels on the ticket detail page
- Backfilling labels for existing tickets

## Technical Changes

- Updated: `jira_integration/models.py`
- Updated: `jira_integration/views.py` — webhook handler
- Updated: `jira_integration/templates/jira_integration/ticket_list.html`
- New: migration `jira_integration/migrations/0002_jiraticket_labels.py`

## Acceptance Criteria

- Incoming webhook saves labels array to `JiraTicket.labels`
- Desktop table shows labels as `badge bg-light text-dark border` badges inline
- Mobile card shows labels below the project/type line
- Tickets with no labels show nothing (no empty space)

## Validation Plan

- Trigger a webhook for a ticket with labels → verify badges appear on list
- Trigger a webhook for a ticket without labels → verify no empty space
