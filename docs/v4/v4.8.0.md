# v4.8.0 — Ticket Attachments

## Goal

Allow files to be attached to ITSM tickets, with a dedicated Attachments tab on the ticket detail page.

## In Scope

- `TicketAttachment` model: FK to Ticket, FileField, original_name, file_size, uploaded_by, uploaded_at
- Migration
- Upload view (POST, login required)
- Delete view (uploader or staff only)
- Attachments tab on ticket detail page: file list with name, size, uploader, date, download + delete
- File size limit: 10 MB default (MAX_UPLOAD_SIZE in settings)
- `MEDIA_ROOT` / `MEDIA_URL` wiring in settings and config/urls.py
- Mobile-first tab layout

## Out of Scope

- File type whitelisting
- Virus scanning
- S3 / external storage
- Attachment preview
- Attachments on Jira tickets or other models

## Technical Changes

- New model: `itsm.TicketAttachment`
- New migration: `itsm/migrations/`
- Updated: `itsm/views.py` — upload + delete views
- Updated: `itsm/urls.py`
- Updated: `itsm/templates/itsm/ticket_detail.html` — Attachments tab
- Updated: `config/settings.py` — MEDIA_ROOT, MEDIA_URL, MAX_UPLOAD_SIZE
- Updated: `config/urls.py` — serve media in debug
- Updated: `docker-compose.yml` — media volume mount

## Acceptance Criteria

- Authenticated user can upload a file to a ticket
- File appears in the Attachments tab with name, size, uploader, date
- Download link serves the file
- Uploader or staff can delete an attachment
- Files over 10 MB are rejected with a clear error
- Tab shows attachment count badge

## Validation Plan

- Upload a file → verify it appears in tab
- Upload >10 MB file → verify rejection
- Delete as uploader → verify removed
- Delete as non-owner non-staff → verify 403
- Mobile: tab and list are usable without horizontal scroll
