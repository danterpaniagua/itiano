# v4.7.3 — Import Source Tagging

## Goal

Automatically tag credentials imported from KeePass (.kdbx) or KeePass XML (.xml) with a source tag so users can filter by import origin.

## In Scope

- `import_credentials` view: attach `_source_tag` key (`"keepass"` or `"keepassx"`) to each entry stored in the session
- `import_confirm` view: get-or-create the source tag and apply it to each created credential alongside any parsed tags
- `import_preview.html`: display the source tag badge on each entry row

## Out of Scope

- Retroactive tagging of previously imported credentials
- Configurable tag names
- Any other tag or import changes

## Technical Changes

- Updated: `vault/views.py` — `import_credentials`, `import_confirm`
- Updated: `vault/templates/vault/import_preview.html`

## Acceptance Criteria

- Importing a .kdbx file → all created credentials have tag `keepass`
- Importing a .xml file → all created credentials have tag `keepassx`
- Source tag is visible in the import preview before confirming
- Source tag appears on the credential list alongside other tags
- Credentials not created (duplicates) are not tagged

## Validation Plan

- Import a .kdbx file → confirm → verify `keepass` tag on each credential
- Import a .xml file → confirm → verify `keepassx` tag on each credential
- Preview page shows the source tag badge
