# v4.6.0 — Action/Trigger Change History + No-Op Save Guards

## Goal

Record every edit made to an Action or Trigger so staff can audit who changed what and when, and review the history directly from the edit form. Also prevent unnecessary database writes when submitting a form or saving the clipboard with no actual changes.

## In Scope

- `ActionHistory` model — one record per field changed per save; fields: `action` (FK), `user` (FK), `field_name`, `old_value` (TextField), `new_value` (TextField), `changed_at` (auto)
- `TriggerHistory` model — same structure, FK to `Trigger`
- History recorded in `action_edit` and `trigger_edit` views by comparing field values before and after `form.save()`
- Tracked fields:
  - Action: `name`, `action_type`, `description_format`, `field_mappings`, `tag_expressions`, `system_user`, `dedup_expression`, `is_active`
  - Trigger: `name`, `source`, `filter`, `action`, `is_active`
- Read-only history section at the bottom of the Action and Trigger edit forms — most recent 20 entries, showing date, user, field, old → new
- **No-op save guard** — `form.has_changed()` check in `action_edit`, `trigger_edit`, and `TicketEditView.post`: shows "No changes detected." and redirects without writing to the DB
- **Clipboard no-op guard** — page view and AJAX `clipboard_save` compare incoming content with current decrypted value; skip write and encryption if equal; AJAX response includes `changed: false`

## Out of Scope

- History for `action_create` / `trigger_create`
- History for `action_toggle` / `trigger_toggle`
- Diffing JSON fields beyond string comparison
- Pagination of history entries

## Technical Changes

- `automations/models.py` — add `ActionHistory` and `TriggerHistory` models
- `automations/migrations/0006_action_trigger_history.py` — `CreateModel` for both
- `automations/views.py` — `_snapshot`, `_record_history` helpers; `action_edit` and `trigger_edit` capture pre-save snapshot, guard with `form.has_changed()`, call `_record_history` after save; history passed to template context
- `automations/templates/automations/action_form.html` — history section (collapsed by default)
- `automations/templates/automations/trigger_form.html` — history section (collapsed by default)
- `itsm/views.py` — `TicketEditView.post` guards with `form.has_changed()`
- `clipboard/views.py` — `clipboard` page view and `clipboard_save` AJAX skip write when content is unchanged

## Acceptance Criteria

- [x] Saving an Action with changed fields creates one `ActionHistory` record per changed field
- [x] Unchanged fields produce no history records
- [x] Edit form shows history section with date, user, field name, old value, new value
- [x] No history is recorded on create
- [x] `TriggerHistory` works identically for Triggers
- [x] Submitting Action/Trigger/Ticket edit with no changes shows info message, no DB write
- [x] Saving clipboard with same content skips encryption and DB write
