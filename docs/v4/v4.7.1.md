# v4.7.1 — KeePass Import

## Goal

Allow users to import credentials from KeePass 2 (.kdbx) and KeePass XML export (.xml) files directly into their vault.

## In Scope

- Upload form at `/vault/import/` — file + optional master password for .kdbx
- Parse `.kdbx` via `pykeepass`; parse KeePass XML export via `xml.etree.ElementTree`
- Map entries to `Credential` (type=password): title→name, URL→url, username→username, password→encrypted_password, notes→notes, tags→tags
- Preview step: parsed entries shown before import, duplicates (same name, same owner) flagged and skipped
- Confirm step: create `Credential` objects for non-duplicate entries
- Session stores parsed entries between preview and confirm
- `pykeepass` added to `requirements.txt`

## Out of Scope

- KeePass groups → team mapping
- SSH key / certificate type detection
- KeePass 1 (.kdb) format
- Export back to KeePass

## Technical Changes

- `requirements.txt` — add `pykeepass`
- `vault/importer.py` — `parse_kdbx(file, password)` and `parse_xml(file)` returning list of dicts
- `vault/views.py` — `import_credentials` (GET/POST upload+preview) and `import_confirm` (POST)
- `vault/urls.py` — `/vault/import/` and `/vault/import/confirm/`
- `vault/templates/vault/import_form.html`
- `vault/templates/vault/import_preview.html`

## Acceptance Criteria

- [ ] .kdbx file with master password imports all entries
- [ ] KeePass XML file imports all entries
- [ ] Duplicate entries (same name) are skipped with a warning count
- [ ] Preview shows entry count before committing
- [ ] Secrets are encrypted with user's personal vault key

## Validation Plan

Export a KeePass database as XML and import it. Verify credentials appear in vault list with encrypted secrets.
