Notes

A per-user note-taking app with notebooks, markdown editing, and note sharing.

Notebooks
  • Create notebooks to organise your notes into groups.
  • A notebook can only be deleted when it is empty.
  • Notes without a notebook appear in All Notes.
Editor
  • Write tab — plain text with markdown syntax.
  • Preview tab — rendered markdown.
  • Save with the Save button or Ctrl+S / ⌘S.
From the JSON Sandbox

Staff can save a JSON Sandbox session as a note (payload, expression or filter, and result); those notes go in a JSON Sandbox notebook created on first use.

Mentions with @

Type @ in the Write tab to mention an object; a list appears (tap a row to pick it):

  • @GITIN-2315 — a Jira ticket (always the Jira one).
  • @ticket:42 — an ITSM ticket.
  • @cred:17 — a vault credential (a link to its read-only page, never the secret).

The list only offers what you can see. Mentions inside code, and things like user@host.com, are ignored. The Preview tab turns each mention into a chip with the current title or name; if you cannot open the object you only see no access, and a removed object shows deleted. Sharing a note never shares the objects it mentions: every reader sees chips according to their own access.

The ITSM ticket, Jira ticket and credential pages list the notes that mention them (only notes you can read) in a collapsed Notes mentioning this card.
