Attachments

Any authenticated user who can view a ticket can upload files via the Attachments tab. Files are stored on disk under media/attachments/.

  • Maximum file size: 10 MB.
  • Download: clicking the filename opens the file directly.
  • Delete: only the uploader or a staff member can delete an attachment.
Tags

Tags are colored labels that can be attached to tickets manually or stamped automatically by the automation engine.

  • Colored pills — each tag has a configurable background color (Bootstrap palette or custom hex). Uncolored tags default to grey.
  • 🤖 prefix — tags created by an automation are marked with a robot icon. Manually added tags have no prefix.
  • Add tag — staff can type a tag name on the ticket detail page, pick a color, and click Add. Existing tag names are suggested via autocomplete.
  • Remove tag — staff can remove any tag from a ticket using the × button on each pill.
Jira Tab

Tickets created by a Jira automation have their External ID set to the Jira issue key (e.g. GITIN-1281). When this matches a known Jira ticket, a Jira tab appears on the ticket detail page showing:

  • Issue key (linked to the Jira ticket page), project, type, and current status.
  • Labels.
  • All files attached to the Jira issue: filename, author, date, and a direct download link from Jira.

The tab is hidden if no matching Jira ticket exists. File content is not downloaded — only metadata from the last received webhook payload is shown.
