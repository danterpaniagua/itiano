Credential Vault

Personal encrypted storage for passwords, SSH keys, and certificates.

Credential Types
  • Password — URL, username, and encrypted password.
  • SSH Key — Encrypted private key, optional passphrase, and plaintext public key.
  • Certificate — Encrypted private key and plaintext certificate PEM.
Visibility
  • Personal — Only you can see it.
  • Team — All members of the selected team can see and copy it. Only the owner can edit or delete it.
Copying Secrets

Secrets are never shown in plaintext. Use the button to copy the decrypted secret directly to your clipboard via a secure AJAX request.

Expiry Warnings

Credentials with an expiry date within 30 days show a warning badge in the list.

SECRET_KEY Rotation Warning

Each user's vault key is encrypted with a key derived from SECRET_KEY. Rotating SECRET_KEY will make all vault credentials unreadable. Export or re-enter credentials before rotating.
